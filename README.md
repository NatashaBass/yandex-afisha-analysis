# Анализ данных сервиса Яндекс Афиша

## О проекте

Исследовательский анализ данных сервиса Яндекс Афиша по заказам билетов за период с июня по октябрь 2024 года.

Цель проекта — исследовать изменение пользовательского спроса и структуры заказов летом и осенью, определить наиболее востребованные категории мероприятий, регионы и билетных партнёров, а также проверить различия в поведении пользователей мобильных и стационарных устройств.

## Задачи

- подготовить и очистить данные;
- объединить данные о заказах и мероприятиях;
- привести выручку к единой валюте;
- обработать выбросы и дубликаты;
- исследовать динамику количества заказов;
- сравнить структуру спроса летом и осенью;
- проанализировать среднюю выручку с одного билета;
- исследовать DAU и пользовательскую активность;
- проверить недельную цикличность;
- проанализировать распределение заказов по регионам;
- исследовать билетных партнёров;
- сравнить поведение пользователей mobile и desktop;
- проверить статистические гипотезы.

## Подготовка данных

Для анализа использовались три датасета:

- 290 849 заказов;
- 22 427 мероприятий;
- 357 записей с курсом тенге.

Данные о заказах и мероприятиях были объединены по `event_id`.

В ходе предобработки:

- обработаны пропуски;
- скорректированы типы данных;
- выручка приведена к российским рублям;
- рассчитана выручка с одного билета;
- созданы признаки месяца и сезона;
- исследованы аномальные значения;
- удалены выбросы по выручке выше 99-го процентиля;
- удалены технические дубликаты.

После обработки в итоговом датасете осталось 287 752 записи.

## Основные результаты

### Динамика спроса

Количество заказов росло на протяжении всего рассматриваемого периода:

- июнь — 34 164 заказа;
- октябрь — 99 279 заказов.

Таким образом, количество заказов выросло примерно в 2,9 раза.

Особенно заметное увеличение спроса наблюдалось осенью.

### Структура заказов

Концерты оставались самой востребованной категорией мероприятий, однако их доля снизилась:

- летом — 42,6%;
- осенью — 37,2%.

Одновременно выросла доля:

- театра — с 20,1% до 25,3%;
- спорта — с 2,5% до 11,2%.

### Выручка с одного билета

Для большинства типов мероприятий средняя выручка с одного билета осенью снизилась.

Наиболее заметные изменения:

- театр: −17,8%;
- ёлки: −15,4%;
- концерты: −12,0%.

Рост наблюдался:

- стендап: +5,8%;
- выставки: +4,9%.

Самая высокая средняя выручка с одного билета в оба сезона наблюдалась у концертов.

### Пользовательская активность

Осенью пользовательская активность увеличивалась от сентября к октябрю.

В среднем за день:

- около 2 764 заказов;
- DAU — около 924 пользователей.

В будние дни пользовательская активность была выше, чем в выходные, при этом средняя стоимость одного билета в выходные была выше.

### Регионы

Распределение заказов по регионам оказалось достаточно концентрированным.

Каменевский регион:

- 26,5% уникальных мероприятий;
- 31,2% заказов.

Топ-10 регионов обеспечивали около 71,7% всех заказов.

### Билетные партнёры

Крупнейшие партнёры обеспечивали основную часть заказов и выручки.

Топ-10 партнёров:

- 90,5% всех заказов;
- 87,6% выручки.

Это показывает высокую концентрацию заказов у крупнейших билетных операторов.

## Статистический анализ

Были проверены две гипотезы о различиях между пользователями mobile и desktop.

### Количество заказов на пользователя

Среднее количество заказов:

- mobile — 2,86;
- desktop — 1,97.

Для проверки использован односторонний t-тест Уэлча.

`p-value < 0,000001`

Различие статистически значимо: пользователи mobile в среднем совершают больше заказов.

### Время между заказами

Средний интервал между последовательными заказами:

- mobile — 6,68 дня;
- desktop — 3,96 дня.

Для сравнения также использован односторонний t-тест Уэлча.

`p-value < 0,000001`

Различие статистически значимо: среднее время между заказами пользователей mobile выше, чем у desktop.

## Вывод

За рассматриваемый период спрос на сервис значительно вырос, особенно осенью.

Концерты сохранили лидирующую позицию, однако структура спроса изменилась: заметно увеличилась доля театральных и спортивных мероприятий.

При росте числа заказов средняя выручка с одного билета в большинстве категорий снизилась.

Заказы и выручка заметно концентрируются в крупнейших регионах и у ограниченного числа билетных партнёров.

Статистический анализ также выявил значимые различия между пользователями mobile и desktop: мобильные пользователи в среднем совершают больше заказов, но интервал между их последовательными заказами также выше.
